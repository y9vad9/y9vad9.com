Dieser Abschnitt enthält Notizen über diese Website selbst – wie sie aufgebaut ist, die Philosophie dahinter und die Werkzeuge, die ich verwende, um sie zu pflegen.

Es ist eine rekursive Schleife: Code über den Code, der den Code anzeigt. Hier findest du Artikel über die Softwaredesign dieses digitalen Gartens, Designentscheidungen (z. B. warum ich mich für eine Graphansicht entschieden habe) und das „Wie“ meines persönlichen Wissensmanagementsystems.

### Tech-Stack
Dieser Garten wurde primär erstellt mit:
*   **Next.js (App Router)** als Kern-Framework.
*   **Tailwind CSS** für das Styling, unter Verwendung eines semantischen Theming-Systems (Light, Dark, Warm).
*   **D3.js / React Force Graph** für die interaktive Visualisierung des Wissensgraphen.
*   **MDX** für die Erstellung von Inhalten, was React-Komponenten direkt in den Notizen ermöglicht.

Alles hier ist Open Source. Du kannst die Implementierungsdetails in den folgenden Notizen erkunden oder direkt [das Repository](https://github.com/y9vad9/y9vad9.com) prüfen.
