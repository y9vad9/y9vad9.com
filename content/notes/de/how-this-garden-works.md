Lassen Sie uns eines klarstellen: Das hier ist kein Blog (zumindest hasse ich es, wenn es als solcher bezeichnet wird). Betrachten Sie es als einen **Digitalen Garten** — einen Raum, inspiriert von Werkzeugen wie Obsidian, in dem ich Ideen wachsen lasse, anstatt sie nur zu posten. Er ist für hocheffizientes Informationsmanagement und schnelle Navigation ohne den üblichen "Webseiten"-Ballast konzipiert. Hier erfahren Sie, wie Sie das Beste daraus machen können.

## Das Drei-Spalten-Layout

Das Notizen-Interface ist in drei Funktionsbereiche unterteilt, um den Kontext immer verfügbar zu halten:

1.  **Linkes Panel (Explorer)**: Ihr Einstiegspunkt. Wechseln Sie zwischen dem Dateibrowser und einer Tiefensuche durch den Inhalt aller Notizen.
2.  **Mitte (Die Notiz)**: Der Hauptlesebereich. Er ist sauber und fokussiert gestaltet, mit einer adaptiven Breite, die den Bildschirm ausfüllt, wenn die Seitenleisten geschlossen sind.
3.  **Rechtes Panel (Werkzeuge)**: Ihr Metadaten-Hub. Greifen Sie auf das Inhaltsverzeichnis zu, navigieren Sie durch eine Notizen-Serie, sehen Sie Backlinks (wer hierher verlinkt) und öffnen Sie den Wissens-Graph.

## Navigation und Tabs

Sie können mit mehreren Notizen gleichzeitig arbeiten, dank des integrierten Tab-Systems in der oberen Navigationsleiste.

*   **Notizen öffnen**: Ein normaler Klick ersetzt den aktuellen Tab.
*   **Neue Tabs**: `Cmd + Klick` (Mac) oder `Strg + Klick` (Windows/Linux) öffnet eine Notiz in einem neuen Tab.
*   **Tabs wechseln**: Verwenden Sie `Alt + 1-9`, um sofort zwischen den Tabs zu springen.

## Erweiterte Suche & Entdeckung

### Befehlspalette
Die **Befehlspalette** ist Ihr globales Werkzeug zur Navigation. Drücken Sie zweimal `Umschalt` oder klicken Sie auf die Suchleiste, um sie zu öffnen. Sie ermöglicht Ihnen:
*   Suche nach jeder Notiz oder jedem externen Link, der auf der Website erwähnt wird.
*   Sofortiger Wechsel von Sprachen oder Designs.
*   Finden einer zufälligen Notiz, wenn Sie Lust auf etwas Neues haben.

### Tag-Filterung
Sowohl die Befehlspalette als auch der Datei-Explorer unterstützen die erweiterte Tag-Filterung. Geben Sie `tag:` gefolgt vom Tag-Namen ein, um Ihre Suche einzugrenzen:
*   `tag:kotlin` (oder `tag:"kotlin"`) — findet alle Notizen mit dem Tag "Kotlin".
*   `tag:"mehrere wörter"` — Sie **müssen** Anführungszeichen verwenden, wenn der Tag Leerzeichen enthält.
*   Sie können Tags mit regulärem Text kombinieren, um spezifische Notizen innerhalb eines Themas zu finden.

### Inhalts-Tiefensuche
Während die Dateiliste normalerweise Titel durchsucht, sucht der **Suchmodus** (`F`) im tatsächlichen Text jeder Notiz und hebt die Treffer für Sie hervor.

## Tastenkombinationen

Der Garten ist vollständig ohne Maus navigierbar. Einzelbuchstaben-Kürzel feuern nur, wenn Sie *nicht* in einem Textfeld tippen — `Cmd + F` öffnet also weiterhin die Browser-Suche.

### Panels & Tabs
| Aktion | Mac | Windows / Linux |
| :--- | :--- | :--- |
| Linkes Panel umschalten | `⌘ + [` | `Strg + [` |
| Rechtes Panel umschalten | `⌘ + ]` | `Strg + ]` |
| Aktuellen Tab schließen | `⌘ + \` | `Strg + \` |
| Zum Tab wechseln (1-9) | `Alt + [1-9]` | `Alt + [1-9]` |

### Linkes Panel (Explorer)
| Aktion | Kürzel |
| :--- | :--- |
| Dateien | `E` |
| Tiefensuche | `F` |

### Rechtes Panel (Werkzeuge)
| Aktion | Kürzel |
| :--- | :--- |
| Inhaltsverzeichnis | `T` |
| Serie | `S` |
| Backlinks & Links | `L` |
| Wissens-Graph | `G` |

### Befehlspalette
| Aktion | Kürzel |
| :--- | :--- |
| Palette öffnen | `Umschalt, Umschalt` ODER `/` |

## Interaktives Wissen

*   **Backlinks**: Am Ende jeder Notiz (und im rechten Panel) sehen Sie andere Notizen, die auf die Notiz verweisen, die Sie gerade lesen.
*   **Scroll-Speicher**: Der Garten merkt sich, wo Sie in jeder Notiz waren. Wechseln Sie zwischen den Tabs, und Sie finden sich genau dort wieder, wo Sie aufgehört haben.
