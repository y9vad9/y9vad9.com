## Трьохпанельний інтерфейс

Інтерфейс нотаток розділений на три функціональні зони, щоб контекст завжди був під рукою:

1.  **Ліва панель (Провідник)**: Ваша точка входу. Перемикайтеся між списком файлів та глибоким пошуком по всьому вмісту нотаток.
2.  **Центр (Нотатка)**: Основна область для читання. Вона має адаптивну ширину, яка заповнює весь екран, коли бічні панелі згорнуті.
3.  **Права панель (Інструменти)**: Центр метаданих. Тут ви знайдете Зміст, Зворотні посилання (хто посилається на цю нотатку) та всі теги саду.

## Навігація та вкладки

Ви можете працювати з декількома нотатками одночасно завдяки вбудованій системі вкладок у верхній панелі.

*   **Відкриття нотаток**: Звичайний клік замінює нотатку в поточній вкладці.
*   **Нові вкладки**: `Cmd + Click` (Mac) або `Ctrl + Click` (Windows/Linux) відкриває нотатку в новій вкладці.
*   **Перемикання**: Використовуйте цифри `1-9` з клавішею Control (Mac) або Alt (Win) для миттєвого переходу між вкладками.

## Пошук та відкриття нових знань

### Палітра команд
**Палітра команд** — це ваш універсальний інструмент для навігації. Натисніть `Shift` двічі, введіть `/` або клікніть на рядок пошуку, щоб відкрити її. Вона дозволяє:
*   Шукати будь-яку нотатку або зовнішнє посилання на сайті.
*   Миттєво змінювати мову або тему інтерфейсу.
*   Знайти випадкову нотатку, якщо хочете почитати щось нове.

### Фільтрація за тегами
І Палітра команд, і Провідник файлів підтримують розширену фільтрацію за тегами. Просто введіть `tag:`, а потім назву тегу:
*   `tag:kotlin` (або `tag:"kotlin"`) — знайде всі нотатки з тегом "Kotlin".
*   `tag:"кілька слів"` — ви **мусите** використовувати лапки, якщо назва тегу містить пробіли.
*   Ви можете комбінувати теги зі звичайним текстом для точного пошуку всередині теми.

### Глибокий пошук за вмістом
У той час як Провідник зазвичай шукає в заголовках, **Режим Пошуку** (`Cmd/Ctrl + Alt + F`) шукає всередині тексту кожної нотатки та підсвічує знайдені збіги.

## Клавіатурні скорочення

Садом можна повністю керувати без миші.

### Панелі та навігація
| Дія | Mac | Windows / Linux |
| :--- | :--- | :--- |
| Згорнути ліву панель | `⌘ + [` | `Alt + [` |
| Згорнути праву панель | `⌘ + ]` | `Alt + ]` |
| Закрити поточну вкладку | `⌘ + \` | `Ctrl + \` |
| Перейти до вкладки (1-9) | `⌃ + [1-9]` | `Alt + [1-9]` |
| Циклічний фокус секцій | `Tab` | `Tab` |

### Пошук та Палітра
| Дія | Mac | Windows / Linux |
| :--- | :--- | :--- |
| Пошук файлів | `⌘ + F` | `Ctrl + F` |
| Пошук за вмістом | `⌘ + ⌥ + F` | `Ctrl + Alt + F` |
| Палітра команд | `Shift, Shift` АБО `/` | `Shift, Shift` АБО `/` |

### Інструменти правої панелі
| Дія | Mac | Windows / Linux |
| :--- | :--- | :--- |
| Зміст (ToC) | `⌥ + C` | `Alt + C` |
| Посилання (Links) | `⌥ + L` | `Alt + L` |
| Усі теги (Tags) | `⌥ + T` | `Alt + T` |

## Інтерактивні знання

*   **Зворотні посилання**: У нижній частині кожної нотатки (та у правій панелі) ви можете бачити, які ще статті згадують ту, яку ви зараз читаєте.
*   **Пам'ять скролу**: Сад пам'ятає, де ви зупинилися в кожній нотатці. Перемикайтеся між вкладками, і ви повернетеся рівно до того місця, де закінчили читання.
