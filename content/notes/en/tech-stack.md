## Kotlin (Prod)
Kotlin has been my go-to language since 2020. What began as an alternative to Java for Android development quickly 
became my default for everything from backend services to multiplatform projects. Even the website you're browsing
now was built with it. Every project I've worked on since 2021 has embraced Kotlin's flexibility and conciseness.

### Stack
- kotlinx.coroutines (Flow, etc.), RxJava (first preferred).
- kotlinx.serialization, Gson (first preferred), Moshi.
- Ktor, OkHttp, Retrofit, Fuel, Okio (first preferred)
- [RSocket](https://github.com/timemates/sdk), [gRPC](https://github.com/timemates/sdk), Rest

### Android

## Java
Java holds a place in my foundation, though I don't use it as much now. My last major project was for a university – [Telegram bot](https://github.com/y9vad9/restaurant-coursework). Before it I used it for various different projects, such as [Sketchcode](sketchcode).

While Kotlin better suits my needs, I still keep up with Java's updates — it's like an old friend you don't see often but never lose touch with.

The same one to Kotlin experience. I used it before.

## PHP
My first programming love. PHP was how I discovered the joy of building things. Even though I've moved on, I respect how the language has evolved. It powered my first large-scale project, _Sketchcode_, and gave me invaluable experience in optimization and scalability.

Stack:
- Laravel
- Json, XML
- etc


Most often I used pure PHP writing not complex CRUDs.

## Python

## TypeScript (Prod)
A more recent addition to my toolkit, TypeScript came into play during [rrpc](https://github.com/timemates/rrpc-ts), a project for generating RPC services using RSocket. 

In addition to that, I'm currently using it on the daily basis for [my work](experience) tasks.
